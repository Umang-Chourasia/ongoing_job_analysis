# Job Market Data Analysis

## 📌 Overview
This project analyzes job postings to understand trends in the Data Analyst job market.  
The goal is to identify:
- Most in-demand skills (Python, SQL, Power BI, etc.)
- Salary patterns across skills
- Location-wise demand for Data Analyst roles

This is a work-in-progress project being built with a learn-and-build-in-parallel approach.

---

## 🎯 Problem Statement
Aspiring data analysts often learn many tools but lack clarity on:
- Which skills are actually demanded by companies
- How different skills impact salary
- Which locations have higher demand

This project aims to answer these questions using real job posting data.

---

## 🛠 Tech Stack
- Python (Pandas, NumPy)
- Power BI (for dashboard & visualization)
- SQL (optional, for analysis)
- Dataset: Kaggle (job postings)

---

## 📂 Project Structure
Some job postings did not disclose company names. These were retained and labeled as ‘Not Disclosed’ to avoid unnecessary data loss.
